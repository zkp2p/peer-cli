---
title: Vault and Delegation
description: Safe workflow for vault creation, pricing changes, and delegation updates.
---

## Goal

Operate a manager-controlled pricing path without losing track of delegation state.

## Sequence

### 1. Inspect current state

```bash
peer vault list --manager 0x1111111111111111111111111111111111111111
peer vault show --id vault-1
peer delegate show --deposit 42
```

### 2. Validate oracle compatibility if needed

```bash
peer oracle supports-inline --escrow-address 0x1111111111111111111111111111111111111111
peer oracle validate-feeds --feeds-file feeds.json
```

### 3. Preview the pricing or delegation change

```bash
peer vault set-rate --id vault-1 --platform wise --currency USD --rate 1.02
peer delegate set --deposit 42 --vault vault-1
```

### 4. Execute only after preview review

```bash
peer vault set-rate --id vault-1 --platform wise --currency USD --rate 1.02 --yes
peer delegate set --deposit 42 --vault vault-1 --yes
```

### 5. Verify post-state

```bash
peer delegate show --deposit 42
peer vault effective-rate --id vault-1 --platform wise --currency USD
peer indexer delegations by-deposit --deposit-id 42
```
